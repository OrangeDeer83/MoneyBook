# 記帳本 MoneyBook

溫暖可愛風格的 Android 記帳 App，用 Kotlin + Jetpack Compose 寫成。

## 功能（v2）
- 記一筆：計算機鍵盤（可直接輸入 120+60）、常用記帳一鍵帶入、分期付款、標籤、備註
- 分類：自訂分類與圖示、子分類、顏色、排序
- 帳戶與帳本：多帳戶與餘額、帳戶間轉帳、多帳本（個人／旅行／家庭分開記）
- 統計：月統計、年度報表、近 6 個月趨勢，可依分類或標籤看
- 日曆：每天花多少一目了然
- 可愛：5 種吉祥物（小鹿、小貓、小熊、小兔、小狗）會依預算換表情、記帳撒花動畫、5 套配色、深色模式
- 資料：備份／還原、匯出／匯入 CSV（v1 的資料會自動搬過來）

## 自動編譯
推送到 `main` 後，GitHub Actions 會自動編出 APK 並發布到 Releases。編譯失敗時，錯誤訊息會直接顯示在 Actions 頁面上。
