# 記帳本 MoneyBook

溫暖可愛風格的 Android 記帳 App（Kotlin + Jetpack Compose）。

## 下載
到 [Releases](../../releases) 下載最新的 `MoneyBook-vX.Y.Z.apk`，用手機安裝即可。

## 主要功能
- 計算機鍵盤、常用記帳、分期、標籤、手續費／優惠、報銷（含部分報銷與回饋）
- 多帳戶、多帳本、信用卡額度與帳單日、帳戶明細
- 日曆（可拖曳移動）、統計（月／年／區間／趨勢、可點選的圓餅圖、下鑽到每筆記錄）、搜尋
- 6 種吉祥物、多套配色、深色模式
- 備份／還原、CSV 匯入匯出
- 資料只存在手機裡；網路只用在抓持股價格（預設關閉，同意後才會連線，只送出代號）
